CONTRIBUTE

Make useful
things better.

The best contributions are specific, reproducible and useful to the people who maintain and use a project.

01

Start with the repository

Read the project README, supported-platform notes and licence before opening a contribution.

02

Report problems clearly

Include the environment, steps to reproduce, expected behaviour and what actually happened. Keep reports focused.

03

Keep changes reviewable

Prefer small pull requests with a clear purpose, tests where relevant and updated documentation.

04

Protect people and systems

Never post passwords, access tokens, private keys or personal information in public issues or pull requests.
