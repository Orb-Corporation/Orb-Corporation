11 NOVEMBER 2026 · RELEASE & ROADMAP

Orb! 0.2.0 released; project targets published

Orb! 0.2.0 was released on 11 November 2026. Its project page reflects the current platform support, command-line tooling and Visual Studio Code integration, while distinguishing experimental Windows and macOS targets from fully supported Linux x86-64.

The current estimated targets are: Orb! Web Development Library — 13 November 2026; Easy File Transportation — 20 November 2026; TASH — December 2026; Universal File Viewer — January 2027; and Orb! performance and optimisation work — during 2027. Filerora remains TBD.

These dates are planning estimates, not guarantees. They may move earlier or later as development and testing progress.
