PROGRAMMING LANGUAGE

Orb!

0.2.0 · Released

Orb! is evolving from a Linux-focused native systems language toward a compiler with additional platform targets and better developer tooling.

Latest release: 11 November 2026 (version 0.2.0).

  • Linux x86-64: fully supported and tested.
  • Windows via WSL2: recommended Windows workflow, using the Linux compiler in WSL2.
  • Native Windows x86-64 and macOS x86-64: experimental targets, not yet executed on real Windows/macOS hardware.
  • VS Code support includes syntax highlighting, snippets, run/build/check commands, diagnostics, tasks and WSL integration.
  • orb doctor and --target linux|macos|windows improve toolchain diagnosis and target selection.

LONG-TERM LANGUAGE GOALS

Orb! beyond systems.

Long term
1. Web development library

Develop a first-party web development library so Orb! can be used to build web applications and interact with browser capabilities, alongside standards such as HTML and CSS.

Estimated target: 13 November 2026.
2. Performance and efficiency

Improve the compiler's optimiser, code generation and runtime efficiency, with the ambition of outperforming C++ on clearly defined, reproducible workloads.

Estimated target: sometime in 2027.

These are goals, not features that have shipped. The current public benchmark notes still describe optimisation limitations; performance claims will require repeatable comparisons under fair compiler settings.

All roadmap dates are estimates.
