VISUAL WORKFLOW AUTOMATION

Flow.

A visual workflow builder prototype for arranging connected steps, conditions and device-side actions on a drag-and-drop canvas.

View prototype source ↗

Prototype · on hold   Development is paused while Easy File Transportation takes priority. No release date is set.

PROJECT STATUS

A prototype,
not a finished product.

Flow currently provides a workflow canvas, local preview engine, conditional branches, variables, HTTP request blocks and execution logs. It is intended to make simple workflows understandable through connected visual blocks.

Development is on hold. The current prototype should not be treated as a stable automation platform or as a replacement for mature automation services.

CURRENT PROTOTYPE

What exists today.

Visual canvas

Add, connect and configure trigger, text, variable, condition, HTTP request and output blocks.

Local workflow preview

Run supported steps on the device and inspect node states, HTTP status and execution logs.

Workflow files

Automatically save locally and import or export workflows as JSON.

Conditional branches

Connect YES and NO paths to represent simple decision logic.

HTTP requests

Send HTTP(S) requests from the device, subject to browser/webview CORS rules and an explicit run confirmation.

Platform shell

The shared application is being built for desktop platforms, with an experimental Android build path.

Important limitations

Flow does not yet execute Orb! code, access local files, send email or provide scheduled triggers. Credential-bearing HTTP headers are disabled until secure credential storage exists. The HTTP request block uses device-side webview networking, so CORS restrictions still apply.
