LOCAL-NETWORK TASK SHARING

TASH.

An experiment in making connected devices useful together — sharing tasks across devices on the same network.

View source on GitHub ↗

Project status: development / experimental. Capabilities depend on the current repository version.

THE IDEA

Devices can
work together.

TASH explores local-network task sharing: a group of devices connected to the same network could contribute resources to suitable tasks.

The project explores distributed work, device discovery and practical collaboration across a local network. It should not be considered a production-ready distributed computing platform unless a specific release says so.
