Build from source

make
make test
orb doctor
orb run examples/hello.orb

Requirements: a C compiler and the platform's assembler/linker. Linux uses GNU binutils; macOS uses Xcode command line tools; native Windows uses MSYS2 / MinGW-w64. See the platform guide before choosing a target.
