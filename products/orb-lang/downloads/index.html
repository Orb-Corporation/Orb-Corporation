Build requirements

  • Linux x86-64
  • A C compiler to build the compiler
  • GNU binutils (as and ld) to assemble and link programs
  • make for the documented build workflow

Build from source

make
make test
orb run examples/hello.orb

The repository README contains optional installation steps and additional compiler commands. The current native target is Linux x86-64; this page does not advertise native Windows or macOS builds.

Experimental software

Orb! is under active development. Review the known limitations and test the compiler in an environment appropriate for development work before relying on it.
