OVERVIEW

One language.
Room to grow.

Orb! is Orb Corporation's programming language project. Its current direction includes native execution on Linux x86-64. Browser and WebAssembly integration has been explored as a development direction, but is not presented here as a released capability.

This page is the home for language documentation, supported targets, releases and development notes.
