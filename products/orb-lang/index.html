A PROGRAMMING LANGUAGE BY ORB

Orb!

A small, statically typed systems language that compiles .orb source files to native x86-64 executables.

Downloads ↓ Source code ↗

Latest release: 0.2.0 (11 November 2026). Linux x86-64 is fully supported and tested; Windows and macOS support remain experimental.

DESIGN

Native output.
No virtual machine.

Orb! compiles directly to native x86-64 executables. The compiler is written in dependency-free C11; its standard library is written in Orb! itself. The Linux runtime uses direct system calls and does not link against libc. The Windows and macOS targets use their platform-specific system interfaces and toolchains.

The compiler pipeline includes parsing, type checking, intermediate representation, optimisation, register allocation and target-specific assembly generation.

LANGUAGE FEATURES

Small core.
Useful building blocks.

Static types

Integer and floating-point types, booleans, strings, pointers, arrays, slices, structs and enums.

Memory control

Explicit allocation and release, pointers, and no automatic garbage collection.

Error handling

Error unions with T!, propagation with try, and handling with catch.

Generics

Generic functions and structs with compile-time monomorphisation.

Standard library

Core I/O, memory helpers, math, strings, file I/O, vectors and target-specific OS layers.

Compiler tooling

Diagnostics, orb doctor, command-line target selection and a Visual Studio Code extension.

The native Windows and macOS outputs have been generated and checked for assembly, but the project documentation states they have not been executed on real Windows/macOS hardware. A native Apple Silicon arm64 backend is not implemented.

LONG-TERM GOALS

Systems today.
Web tomorrow.

Orb! is intended to grow beyond its current systems-programming focus. Two major development goals guide its longer-term direction:

Web development library

Build a first-party library that lets developers use Orb! in web development and interact with browser capabilities, while working alongside web standards such as HTML and CSS.

Estimated target: 13 November 2026.Future goal
Higher performance and efficiency

Improve code generation, optimisation and runtime efficiency, with the long-term ambition of outperforming C++ in carefully defined, reproducible benchmark workloads.

Estimated target: sometime in 2027.Long-term ambition

These are development goals, not current capabilities or performance claims. The public benchmark notes in the repository describe the compiler's present limitations and measured results.
