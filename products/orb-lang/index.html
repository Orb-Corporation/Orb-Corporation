A PROGRAMMING LANGUAGE BY ORB

Orb!

A small, statically typed systems language that compiles .orb source files straight to native x86-64 Linux executables.

Downloads ↓ Source code ↗

Current target: Linux x86-64. The project is under active development; consult the repository for the current implementation status.

DESIGN

Native output.
No virtual machine.

Orb! compiles directly to native executables. Its compiler is written in C11, while the standard library is written in Orb! and embedded into the compiler. The current design does not rely on a virtual machine, garbage collector or libc.

The compiler pipeline includes parsing, type checking, intermediate representation, optimisation, register allocation and x86-64 assembly generation. See the architecture document for implementation details.

LANGUAGE FEATURES

Small core.
Useful building blocks.

Static types

Integer and floating-point types, booleans, strings, pointers, arrays, slices, structs and enums.

Memory control

Explicit allocation and release, pointers, and no automatic garbage collection.

Error handling

Error unions with T!, propagation with try, and handling with catch.

Generics

Generic functions and structs with compile-time monomorphisation.

Standard library

Core I/O, memory helpers, math, strings, file I/O and a generic vector.

Testing

The repository includes regression checks and a differential fuzzer. Test counts can change as the project evolves.

A FIRST LOOK

Hello, Orb!

fn main() {
    x := 10;
    y := 20;

    print(x + y);
}
