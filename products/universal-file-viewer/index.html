DESKTOP FILE INSPECTION

Universal
File Viewer

A desktop utility prototype for identifying and inspecting known, unfamiliar and extension-mismatched files.

Prototype   Estimated target: January 2027. The date may change.

PURPOSE

Look inside
the file.

Universal File Viewer is designed to help users understand what a file contains, especially when its extension is missing, misleading or unfamiliar.

The current prototype is a Python desktop application built with PySide6. It focuses on inspection and does not execute the files it opens.

PROTOTYPE CAPABILITIES

Inspect before you guess.

Format detection

Uses file signatures (magic bytes), not just the filename extension, to help identify formats.

Metadata

Displays basic information about the selected file and its detected type.

Text preview

Attempts common text encodings such as UTF-8, UTF-16 and ASCII when a text view is appropriate.

Hex viewer

Provides a lazy, chunked hexadecimal view for inspecting raw file contents.

Container awareness

Distinguishes several ZIP-based formats, including Office documents and package files.

File analysis

Includes preliminary entropy and printable-character analysis for unfamiliar data.

Prototype, not a public release.

There is no public download on this page yet. Supported formats, platform compatibility, reliability and the final interface are still subject to development and testing.
