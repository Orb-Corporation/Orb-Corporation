BROWSER-BASED FILE CONVERSION

Filerora.

A planned file-conversion toolkit for common media, document, code, data and archive formats.

Planned   Release target: TBD.

THE PRINCIPLE

Your files stay
on your device.

Filerora is being conceived as a browser-based converter with local processing as a core design requirement. The intended architecture avoids uploading user files to an Orb-operated conversion server.

This is a design goal, not a claim about a released service. Filerora is not available yet, and its final browser requirements and conversion compatibility have not been established.

PLANNED FORMAT CATEGORIES

One toolkit.
Many file types.

Images

Common raster and web image formats.

Audio & video

Media conversion, subject to browser codec support.

Documents

Document formats where browser-compatible conversion is practical.

Code & data

Text-based formats, structured data and developer-oriented files.

Archives

Common archive formats, depending on browser-side library support.

Local processing

Designed to process files on the user's device rather than upload them to a conversion backend.

Compatibility will be explicit.

Not every format can be converted in every browser. Supported input and output pairs will need to be documented and tested before release.
